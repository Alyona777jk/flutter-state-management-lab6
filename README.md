# Практична робота 6.1: Базовий State Management у Flutter
**Варіант 1: Лічильник з історією**
Застосунок-лічильник із можливістю зміни кроку ($1 / 5 / 10$), веденням історії всіх дій (збереження часу, типу операції, значень до та після) та окремим екраном перегляду історії. Реалізовано захист від від'ємного значення з виводом текстового попередження для користувача.

Проєкт виконано у 2 етапи для демонстрації архітектурного еволюціонування стану:
* **Stage 1 (`stage-1-lifting`):** Спільний стан піднято до найближчого спільного предка (`MyAppState`) та передано через конструктори віджетів і колбеки (`setState`).
* **Stage 2 (`stage-2-inherited`):** Спільний стан винесено в `ChangeNotifier` (`CounterNotifier`) та надано через `InheritedNotifier` (`CounterScope`). Передавання через проміжні віджети (prop drilling) повністю усунуто.
